# Instâncias PMP

Área reservada para modelos e registros de instâncias PMP relacionados ao
trabalho no Replit. Os arquivos devem conter somente configuração
documental, parâmetros públicos ou placeholders.

## Modelo

```text
Nome da instância:
Finalidade:
Conta responsável:
Projeto relacionado:
Entradas necessárias (nomes, sem valores secretos):
Passos de retomada:
Critérios de conclusão:
Observações:
```

Não salvar tokens, senhas, chaves, cookies ou qualquer credencial real.
