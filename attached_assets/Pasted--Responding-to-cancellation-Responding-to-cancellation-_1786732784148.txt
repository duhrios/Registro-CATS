A imagem confirma um problema no schema do Supabase, não no usuário ou na senha.

O log da API mostra:

column staff_profiles.must_change_password does not exist

A tabela do Supabase está em uma versão antiga. Para corrigir:

Abra o projeto no Supabase Dashboard.
Acesse SQL Editor.
Execute este SQL:
alter table public.staff_profiles
  add column if not exists must_change_password boolean not null default false;
alter table public.staff_profiles
  add column if not exists is_active boolean not null default true;
alter table public.staff_profiles
  add column if not exists password_changed_at timestamptz;
alter table public.providers
  add column if not exists notes text;
alter table public.providers
  add column if not exists responsible_department text;
alter table public.providers
  add column if not exists service_valid_until date;
alter table public.provider_visits
  add column if not exists exit_at timestamptz;

Depois, atualize a página e tente entrar novamente.
